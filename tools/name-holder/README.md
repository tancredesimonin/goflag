# goflag

**This package is a signpost. The tool ships as [`@goflag/cli`](https://www.npmjs.com/package/@goflag/cli).**

```sh
npx @goflag/cli https://example.com
```

Everything under the goflag brand lives in the `@goflag` scope — `@goflag/cli`
today, `@goflag/next` next. One scope, one place to look. This package exists so
that the bare name points at the right one rather than at nothing, or at
somebody else's.

`@goflag/cli` is a lean CLI that audits a site for broken links, missing
translation pages, and missing or misconfigured SEO metadata. It installs the
`goflag` command.

Source, issues and documentation: <https://github.com/tancredesimonin/goflag>
